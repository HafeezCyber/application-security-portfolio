
# Application Security Portfolio

Practical demonstrations of application security, secure code review, vulnerability triage, threat modelling, and DevSecOps automation.

## Portfolio Objectives

- Identify and validate security vulnerabilities.
- Demonstrate secure code remediation.
- Automate security assessments using Semgrep and Trivy.
- Document findings, evidence, and remediation verification.
- Build reproducible security engineering demonstrations.

## Project Status

Initial repository setup. Technical demonstrations will be added incrementally.
